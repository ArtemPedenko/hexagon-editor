# Правила работы в проекте

## Обязательная проверка изменений

Перед завершением любой задачи, изменяющей код, агент обязан:

1. Запустить релевантные автоматические проверки. Минимальный набор для изменений
   в проекте: `pnpm test`, `pnpm typecheck` и `pnpm lint`. Если какая-либо команда
   неприменима к затронутому пакету, нужно явно указать причину в итоговом отчёте.
2. Для изменений, затрагивающих UI, запустить приложение и проверить результат в
   браузере: открыть соответствующий сценарий, убедиться, что он работает без
   ошибок в консоли, и визуально сверить ключевое состояние интерфейса.

Команда для запуска playground: `pnpm dev`.
